# Security

Do not post credentials, private logs, or personal preferences in issues. Use GitHub’s private vulnerability reporting for sensitive reports when available; otherwise open a minimal issue asking for a private contact without disclosing the vulnerability details.

Accessibility permits broad UI control. Loki limits its own discovery to menu-extra trees and user-selected activation. On macOS 14 to 26, Loki posts synthesized Command-drag events only when you click Apply in Menu bar, and only between menu-bar icons and its divider. On macOS 27, hiding instead calls one undocumented Apple interface (MenuBarClientCore), resolved at runtime and disabled automatically if it is absent or has changed; it receives only bundle identifiers of apps to keep visible. Report any path that reaches unrelated document content, or that clicks or drags outside the validated menu-bar bounds.

Release artifacts should be Developer ID signed and notarized, with SHA-256 checksums; [docs/RELEASING.md](docs/RELEASING.md) covers the process. A source build is ad-hoc signed unless the builder supplies a signing identity. Preview releases are not a security or compatibility guarantee.

The optional Quick Chat add-on launches official Claude Code or Codex executables directly with argument arrays and sends prompts through stdin, never through a shell command. A manually selected client is executable code and must come from a trusted source. Claude runs with tools, customizations, hooks, and MCP servers disabled. Codex ignores user configuration, disables shell tools, connected apps, hooks and user-configured MCP servers, and uses a read-only sandbox with no approval prompts. Provider and administrator policy can still constrain these clients. Quick Chat is intended for text conversations, not unattended computer actions. Requests have timeouts and cancellation; update the client when flags are unsupported rather than removing those restrictions.

Reloadable packages are disabled until explicitly enabled. Approval binds to a hash of all package files, including hidden helpers; changed code needs fresh approval. Loki validates IDs, paths, regular-file types, size limits, and command/input schemas. It rechecks package contents before execution. Local custom interfaces can invoke only declared scripts from their enabled package. These controls are not a native script sandbox: an enabled script has the current account’s file and network access, and can deliberately start detached processes. Stop and timeouts terminate the command process group and bound pipe reads. Never enable an untrusted package. See [the add-on API guide](addons/README.md).
